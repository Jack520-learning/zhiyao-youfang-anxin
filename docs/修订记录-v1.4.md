# 修订记录 v1.4

日期：2026-11-17

## 拍照识药与拍照加药

- 修复拍照加药仅等待视觉模型 8 秒的问题。实测视觉识别约需 18 秒，现已将客户端等待上限调整为 50 秒，服务端上游请求上限为 45 秒，并返回明确的超时或服务错误。
- 相机照片与相册照片的有效边长提高至 2400 像素，JPEG 质量提高至 0.92，减少药名和规格文字因压缩而丢失。
- 本机 OCR 从固定整块识别改为自动版面识别；低质量结果会增加一次灰度、对比度增强与稀疏文本复核。
- 增加药品目录字形纠错，例：将 OCR 产生的“未磺酸握所地平户”纠正为“苯磺酸氨氯地平片”，同时避免“维生素 B6”被误纠为“维生素 B1”。
- 视觉候选与本机 OCR 结果改为交叉合并。视觉模型超时时仍可使用 OCR，并通过药品目录纠正常见错字，不再过早判定为“未识别到药物”。
- 强制区分单片规格、包装数量与每次实际服用量。“5mg”“28片/盒”等信息不会再自动填入“每次服用剂量”。
- 视觉提示词改为优先逐字读取最大且最具体的药名，覆盖药盒、瓶签、铝箔板、说明书、处方笺和散装药片；降低遗漏多药包装的概率。
- 移除视觉模型根据药名估算价格的行为。只有包装或价签明确写出的价格才进入识别结果。

## 多药对账与中药材

- 多药对账同时使用视觉药名和 OCR 药名，并按规范化名称去重，不再把整行说明书或广告文字直接当作药名。
- 中药材文本匹配由“整段文字完全匹配”改为在整段 OCR 中查找药名和别名，支持“枸杞”“宁夏枸杞”“杭菊”等写法。
- 新增 OCR 纠错、规格剂量分离、多药候选合并、药材段落识别的回归测试。

## 验证
