# 安心药伴 V1.3 修订记录

> 日期：2026-11-14

## 本轮修订

1. 语音输入状态不再改变输入栏宽度或高度：语音键和发送/结束键使用固定宽度，识别状态只改变颜色与阴影。
2. 问药页“拍照识药”通过 `getUserMedia` 打开实时摄像头取景并拍摄，同时提供系统相机、相册和重试兜底，不再只依赖文件输入框。
3. 拍照后自动执行中文 OCR、字段提取、当前用药风险核查和回答生成。
4. 回答包含药名、剂量、次数、服用时间、风险、下一步和价格。
5. 价格只从包装文字、购买记录或用户填写内容读取；缺失时明确显示“暂无可靠价格数据”，禁止模型猜价。
6. 拍照加药自动填充药品资料，所有关键字段可继续修改；确认后才进入风险核查。
7. 已确认的药物资料会按家庭档案持久保存。再次识别同一药物时复用用户确认过的药名、剂量和治疗记录，形成可审核的“学习”结果。

## 安全边界

- 拍照识别的初步结果不会被自动当成已确认事实。
- 自动分析使用本地风险规则，回答中明确标记资料不足。
- 未完成人工确认时，该药物不会被自动加入当前服用清单。
- 不会把某一位老人的单次数据直接训练成通用医学知识。
