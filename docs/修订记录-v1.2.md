# 安心药伴 V1.2 修订记录

> 日期：2026-11-14

## 本轮修复

1. 问药页面首次打开固定在顶部，不再自动滚动到底部；历史消息折叠，只展示最近 5 条。
2. 今日页“我不舒服”不再跳转问药，直接发送家属危险通知，并在当前页显示发送状态和联系人电话。
3. 长按语音不再因短暂停顿立即结束；持续按住时会自动延续识别，并提供“结束语音”按钮。
4. 拍照入口改为原生文件标签，分别提供“打开相机拍照”和“从相册选图”，避免程序化点击受到浏览器限制。
5. 从今日页进入拍照加药后，返回按钮固定回到今日，不再跳到用药清单。
6. 问药页改为单栏紧凑布局：拍照识药、当前药物数、核对步骤、最近消息和输入区放在同一视觉流中。
7. 问药页增加“拍照识药”；识别完成并保存后可继续让 AI 根据该药名、剂量、次数和时间解释，不再复用通用答案。
