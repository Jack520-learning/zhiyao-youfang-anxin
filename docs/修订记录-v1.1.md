# 安心药伴 V1.1 修订记录

> 日期：2026-11-14

## 本轮修复

1. 在每种药物的列表和详情页增加独立提醒开关。
2. “文字大小”增加标准、大字、特大三档，实际缩放整个老人端页面；高对比度独立控制。
3. 语音朗读开关现在会阻止自动 TTS，关闭时手动朗读按钮同步禁用。
4. 搜索框增加中文输入法 composition 处理，并在搜索栏后增加按住语音搜索。
5. 语音识别改为持续识别，按住期间不会因短暂停顿立即结束；支持明确的“结束语音”按钮。
6. 今日页返回改为固定返回今日；服药操作后显示“点错了，撤销”，可恢复操作前状态。
7. 用药页同时提供“拍照加药”和“输入药名加药”。
8. “我的健康资料”增加编辑、年龄范围校验和保存入口。
9. 今日时间线和药物详情显示计划时间、实际记录时间与状态。
10. 点击“我不舒服”会写入家属即时信息，并尝试通过后端推送通知授权家属。
11. 问药页按住语音时，发送按钮切换为“结束语音”。
12. 新增和修改剂量时校验数字、单位及合理上限。
13. 每日次数可在 1–4 次和按需之间选择，并自动生成第 1、2、3、4 次用药时间。
14. 问药识药调整为第一个一级入口，并位于首页首要操作位置。
15. 问药会按具体药物读取档案；不同药物返回各自剂量、次数、时间；没有具体药名时先追问。
16. 药物添加、药物详情、漏服处理等页面使用固定父级返回路径，减少跳转混乱。

## 数据兼容

- 旧版药物记录缺少 `reminderEnabled` 时默认视为开启。
- 旧版偏好缺少字体档位时默认使用大字模式。
- 旧版家庭摘要缺少即时信息时自动初始化为空数组。
- 现有 IndexedDB 档案通过 Zustand merge 迁移，不要求重新建档。

## 验证

- `npm run build` 通过；
- 12 项自动化测试通过；
- 浏览器验证药物提醒开关、手动加药、剂量上限提示、多时段时间框、字体缩放、具体药物回答和家属不舒服提醒。
